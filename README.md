# 🚀 Aetheris Launcher

**Aetheris Launcher** — современный кастомный лаунчер для Minecraft, созданный специально для стабильной работы и быстрой загрузки сборок (включая **Create: New World**).

---

## 🌟 Ключевые возможности

1. **Импорт сборок из CurseForge (.zip) без Overwolf**:
   - Перетащите `.zip` архив сборки в окно лаунчера (Drag & Drop) или выберите через интерфейс.
   - Лаунчер распакует `overrides` (конфиги, скрипты, шейдеры) и быстро скачает моды через зеркала.

2. **Быстрая загрузка без прокси и VPN**:
   - **Зеркало BMCLAPI**: Высокоскоростная загрузка манифестов Mojang, библиотек, ассетов и клиентов Minecraft.
   - **Гибкая сеть**: Поддержка прямого соединения, системного прокси или кастомного локального прокси.

3. **Авторизация**:
   - **Microsoft OAuth 2.0 (Device Code Flow)**: Вход через официальный `microsoft.com/link` без необходимости ввода пароля в лаунчере.
   - **Оффлайн режим (Quick Play)**: Возможность играть под любым ником на локальных/своих серверах без лицензии.
   - Автоматическое сохранение активного аккаунта между запусками.

4. **Изолированные инстансы**:
   - Каждая сборка хранится в отдельной папке `instances/<ИмяСборки>/`.
   - Моды, миры и конфиги не смешиваются.

5. **Управление Java**:
   - Автоматическое определение установленных версий Java в системе (Java 8, 17, 21, 24).
   - Автозагрузка необходимой версии Java при скачивании инстанса.

6. **Автономность (Single-File .EXE)**:
   - Лаунчер собирается в один исполняемый файл `AetherisLauncher.exe`, не требующий предустановленного .NET.
   - Можно скинуть один файл другу или запускать из любой папки.

---

## 🛠 Сборка проекта

### Требования
- [.NET 10 SDK](https://dotnet.microsoft.com/)

### Команда сборки единого .exe:
```bash
dotnet publish -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -o ./
```
После сборки готовый `AetherisLauncher.exe` появится в корне проекта.
